# framedock

Frame CSV/TSV dock tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/framedock/

## Install / run

```bash
git clone https://github.com/theworker02/framedock.git
cd framedock
node src/cli.js
node --test
```
